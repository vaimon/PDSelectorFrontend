# E22 — Визуальное выравнивание team-selection под дизайн-систему Console

Цель: чтобы при переходе из core (`pd-mmcs.ru`) на `teams.pd-mmcs.ru` пользователь видел
**одну визуальную семью**, а не два разных продукта. Это выравнивание по токенам, **не** переписывание
логики (redux/axios/роутинг не трогаем).

Вся работа ведётся **в этом форке** (`vaimon/PDSelectorFrontend`). Доступа к репозиторию core не нужно —
всё необходимое лежит в этой папке `design/`. Прогресс и ревью — по задачам в трекере этого форка.

---

## Что в пакете (`design/`)

| Файл | Назначение |
|---|---|
| `theme.css` | **Контракт.** Токены Console (палитра light+dark, сайзы, шрифты) как CSS-переменные. Источник истины — не подбирать значения на глаз, а импортировать и использовать `var(--token)`. |
| `fonts.js` | Готовый стартер подключения самохостных шрифтов (Golos Text + JetBrains Mono) через `@fontsource`. Заменяет CDN-шрифты. |
| `logo-ts.svg` / `logo-ts-dark.svg` | **Новый логотип team-selection** — `‹ ›`-скобки core + пиктограмма команды (акцент), семья Console (свет / тьма). Заменяет маскот-бейджи `logo3.png`/`logo4.png`. |
| `reference/console-target.html` | **Цель дизайна.** Три экрана форка (`/login`, `/teams`, `/teams/:id`) — строго те же компоненты, перерисованные в Console (свет/тьма, тумблер справа сверху). Открыть в браузере. Реальные шрифты Golos/JetBrains вшиты. |

### Логотип

Текущие `logo3.png` / `logo4.png` (робот / бейдж «Team Builder») — убрать. Новый mark —
`logo-ts.svg` (светлая тема) / `logo-ts-dark.svg` (темная тема): серые `‹ ›`-скобки core (идентичны родному mark) +
пиктограмма команды в акцентном синем. **Чистые вектора, без зависимости от шрифта** — можно и через
`<img src>`, и инлайном. Инлайн-компонент на CSS-переменных (`var(--accent)`, `var(--text-3)`) даст
автоследование тумблеру свет/тьма. Заодно поправить `<title>` (`index.html`: `Vite + React` →
осмысленный) и favicon.

## Объём (Tier 1 — токенизация CSS)

Стек форка — **обычный CSS** (19 файлов `*/style.css`), не MUI. Поэтому подход — переменные, без
перестройки разметки:

1. Импортировать `theme.css` один раз на входе приложения (`src/index.css` или `src/main.jsx`).
2. Подключить шрифты по `fonts.js` (см. ниже) — и **удалить** CDN-подключения.
3. Пройтись по 19 CSS-файлам, заменяя захардкоженные цвета/радиусы/отступы на `var(--token)`.
4. Темная/светлая тема — реальный тумблер в шапке, переключает `<html data-theme="dark">`.

**Косметическая правка ключевых страниц (в рамках тех же PR).** На `/login`, списке команд и карточке
команды — подтянуть очевидно устаревшую вёрстку: отступы, иерархию, убрать визуальный шум, привести
к плотности Console. Без новых фич, без MUI, без смены фреймворка вёрстки — только «перестать выглядеть
устаревшим». Остальные страницы — чистая токенизация без перекройки.

## Первый шаг (спайк — до полного прохода)

Прежде чем переписывать все 19 файлов, сделать **один экран `/login`** на токенах как proof —
чтобы вживую оценить эффект «та же семья». Показать на ревью, получить «ок» на направление,
затем полный проход. Так дешевле откатить, если что-то в тон не попадает.
